# Security

We aim to respond to security reports within 14 days of receipt. The scope of this project is the code and the ontology content.

Report security issues to the repository maintainers via a private security advisory rather than the public issue tracker.

## Supported scope

Security reports for:
- Code vulnerabilities in this repository
- Factual errors in the ontology (specifically, whether the ontology accurately represents the cited sources)

Corrections to citations or external framework references are welcome as issues with a link to the relevant source.

## Out of scope

- Matters unrelated to the code or ontology content
